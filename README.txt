allaigenerator (prototipe web statis)

Struktur:
  index.html        halaman utama (login + aplikasi)
  css/style.css     gaya tampilan
  js/app.js         logika (model, kredit, generate simulasi)
  images/           logo.svg, favicon.svg, hero.svg

Cara pakai: upload isi ZIP ke hosting statis (Netlify, Cloudflare Pages, GitHub Pages, dll)
atau buka index.html langsung di browser.

Catatan: ini prototipe. Login Canva dan hasil generate masih simulasi, kredit disimpan di browser.
Edit daftar email yang diizinkan di js/app.js (variabel WHITELIST).
